# 研究纲领

## 研究对象

玩笑是一种邀请：说话者邀请听者暂时用另一套规则理解一件事。这个定义是项目工作定义，不是已经确立的学术共识。

分析单位是一次“玩笑事件”：文本或动作、说话者、听者、关系、场景、呈现方式及反应。脱离这些条件，收藏一句话不足以解释它为何成功。

## 核心问题

1. **内容**：哪些预期偏移能产生趣味？反转、双关、荒诞、具体化有什么差异？
2. **理解**：需要多少背景知识？何时是恰好的顿悟，何时只剩困惑？
3. **表达**：信息顺序、长度、口气、停顿和媒介如何改变效果？
4. **关系**：同一句话由朋友、陌生人、上级说出，会产生什么变化？
5. **情境**：轻松聊天、尴尬现场、疲惫时刻分别需要什么？
6. **学习**：训练能否改善创作？能否迁移到新题材和新受众？
7. **极限**：人在衰老、告别或痛苦中，怎样保留开玩笑的主动权？

## 不把不同目标挤进一个总分

| 指标 | 测量方式 | 能说明什么 |
|---|---|---|
| 好笑程度 | 0—6 私下自评 | 主观趣味，是首轮主要指标 |
| 理解程度 | 0—6 自评；可另问笑点在哪里 | 是否跟上表达；自评不等于客观理解 |
| 意外程度 | 0—6 自评 | 是否偏离预期 |
| 不适程度 | 0—6 自评 | 是否造成反感、压力或难堪 |
| 愿意再听 | 0—6 自评 | 是否愿意继续这种互动 |
| 外显反应 | 无反应、微笑、出声笑、未观察 | 有无笑的行为，不能代替好笑评分 |
| 接话情况 | 另记有无自发接梗及内容 | 是否有共同玩的空间 |

量表为项目自定工具，未经心理测量验证。先检查参与者是否理解题意；不拿它作人格诊断。

## 工作模型

趣味可能由这些环节共同影响：建立预期 → 发生偏移 → 听者获得理解或进入荒诞规则 → 感到这次互动可以接受 → 产生反应。

这个模型用于排查失败，不是必要充分条件。无厘头可能保留未解决的矛盾；有人觉得好笑却不笑；同一句也可能同时好笑且冒犯。不能把“不适”从“好笑”里自动减去，伪造一个科学总分。

## 可检验假设清单

| ID | 项目假设 | 初步检验 | 可能推翻它的结果 |
|---|---|---|---|
| H01 | 关键揭示靠后，对一部分短文本更有效 | E001 信息顺序对照 | 两版本接近，或靠前版更好 |
| H02 | 具体细节比抽象标签更容易产生趣味 | 同一题材的细节版本对照 | 细节只增加阅读负担 |
| H03 | 背景知识有助于某些圈内梗 | 测熟悉度，比较背景说明条件 | 说明消除了悬念，降低评分 |
| H04 | 轻微自嘲比点名嘲讽更易被陌生受众接受 | 虚构情境，比较对象 | 自嘲被读成索取安慰 |
| H05 | 口头停顿存在情境相关的合适范围 | 同一录音内容、不同停顿 | 差异很小或因听者而反转 |
| H06 | 反复出现的元素可能形成回扣优势 | 独立短故事，有/无前置线索 | 重复被认为烦或过于可预测 |
| H07 | 训练改善可以迁移 | 训练前后，用新题目、新评者盲评并设对照 | 只会改熟题，迁移不成立 |

这些都是待验证假设。文献支持某种机制，不等于已经证明本项目的具体建议。

## 研究递进

先研究中文短文本；再研究聊天中的接话；再研究口头表演；最后讨论跨人群与复杂情境。跨领域素材包括语言、日常行为、技术、组织生活、叙事和人际互动。先积累低成本可比较样本，不以搜集越多领域替代研究质量。

首次探索不声称代表“中国人”“年轻人”或“人类”。便利样本的结论只覆盖相近的参与者、题材与呈现条件。
