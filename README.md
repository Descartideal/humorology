# 《有趣玩笑学》

**把逗人笑这件事，认真研究起来。**

Humorology · 中文幽默研究与创作实验项目

为什么有的玩笑一句就响，有的解释三遍更冷？为什么朋友说是梗，陌生人说就像挑衅？为什么同一句话，换一个结尾、一个停顿、一个场合，效果完全不同？

我们想把这些问题变成能讨论、能创作、能实验、能复查的研究：**研究怎样在具体的人、关系和情境里，开出别人愿意接住的有趣玩笑。**

从笑点的机制到冷场的原因，从中文日常接梗到人生最后一个玩笑，这个仓库正在搭建一间开放的幽默实验室。欢迎带着你的好笑话来，也欢迎带着那个怎么改都不好笑的版本来。

> “快老死的时候还能不能开个有趣的玩笑？”
>
> “其实不有趣也可以。”

项目诞生于 2026 年 10 月 12 日的一段聊天：“快老死的时候还能不能开个有趣的玩笑？”“其实不有趣也可以。”这个问题同时包含两个目标：让人觉得好笑，以及在某个时刻仍能一起玩。两者都值得研究。

## 这里有什么值得看

- **13 项相关研究笔记**：把幽默心理学、中文语料标注、会话笑声和真人评测的方法接起来，每项附来源与边界。
- **12 种创作机制**：反转、双关、尺度错位、规则迁移、回扣、反笑话……每种都配一个操作方向和失败路径。
- **12 条中文原创候选**：不只给句子，也分析它可能在哪里失效。
- **一套能开跑的对照实验**：6 组 A/B 材料、分配规则、评分表、缺失处理和分析方案。
- **一个值得慢慢研究的专题**：当好笑已经不是最重要的事，一个玩笑还能留下什么？

第一版最重要的成果是把问题和方法准备好了。**真人效果还没有验证。** 我们会让结果决定哪些建议留下，也会保留那些没有奏效的尝试。

## 当前状态

- 已建立：研究问题、机制分类、13 条研究笔记、12 条原创候选、6 组 A/B 材料、首轮实验和数据规范。

- 全部案例都是本项目生成的创作草案，未验证好笑，也不保证此前没有类似表达。
- CSV 评分文件只有表头；没有把想象中的评价写成真实数据。

## 最小工作循环

观察一个具体场景 → 写出受众的预期 → 设计一种偏移 → 写两个版本 → 让自愿参与者独立评价 → 保留失败 → 修改 → 换一批人再测。

先用实验检验“这几个版本对这批人是否更有效”，再逐步扩大结论。这里不把“所有人都笑”当作唯一目标，也不承诺一条万能公式。

## 今天就能做的事

1. 读创作手册，写一个自己的日常小困境。
2. 读 E001，先用 4—6 位自愿参与者检查材料能否读懂。这个阶段只修材料，不作效果结论。
3. 锁定材料与方案，再启动探索性评分；把原始记录填入 `数据/ratings.csv`。

研究规则：区分文献发现、项目推论和待验证经验；允许“没有效果”；记录受众与情境；不把别人的不舒服解释成“没幽默感”。
