# E001：关键揭示靠后，会不会更好笑？

状态：设计草案，未启动。正式收集前填写冻结日期、执行人和材料版本；任何修改均留新版本。

## 借鉴来源

Gorenz & Schwarz（2024）采用隐藏创作来源的真人评分，并使用 0—6 的趣味量表：[原论文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0305364)。本实验借鉴来源隐藏和量表端点，不声称复制其研究。

HaHackathon 将幽默与冒犯分别评定，并关注评分分歧：[任务论文](https://aclanthology.org/2021.semeval-1.9/)。本实验同样保留单人评分，不只保存平均数。

## 问题与设计

比较同一组信息的“较早揭示 A”与“较晚揭示 B”。主假设：B 的平均好笑评分高于 A。无差异或 A 更好也属于可接受结果。

六组材料见 `数据/E001_materials.csv`。A/B 都由本项目生成。每人读六条，每组只看一个版本；每人三个 A、三个 B。题材、信息顺序与语法自然度可能交互，结果只能解释为这些版本的比较，不能证明纯粹的位置因果效应。

## 材料试读

先请 4—6 位自愿中文读者检查：是否读懂、句子是否自然、哪里第一次看出表达的转向。试读者不进入正式样本。

若 B 实际上没有较晚揭示，修材料；若两个版本表达的事实不同，修材料。自然度不一致则先修，或在报告中明确保留的混杂。试读阶段可以改；正式收集后不能按评分挑材料。

## 参与者与分配

探索目标：24 位能流畅阅读中文的自愿成年人，每人约 5—10 分钟。不把 24 当作足够检测效果的证明。参加者能跳过或退出，独立作答，不互看答案。

准备 12 张分配卡：L1、L2 各与六种顺序组合。每张卡复制两份，共 24 张，打乱后依次发给参与者。仅由执行人保留卡与编号的对应。

| 材料组 | P01 | P02 | P03 | P04 | P05 | P06 |
|---|---|---|---|---|---|---|
| L1 版本 | A | B | A | B | A | B |
| L2 版本 | B | A | B | A | B | A |

| 顺序 ID | 阅读顺序 |
|---|---|
| O1 | P01 → P02 → P03 → P04 → P05 → P06 |
| O2 | P02 → P03 → P04 → P05 → P06 → P01 |
| O3 | P03 → P04 → P05 → P06 → P01 → P02 |
| O4 | P04 → P05 → P06 → P01 → P02 → P03 |
| O5 | P05 → P06 → P01 → P02 → P03 → P04 |
| O6 | P06 → P01 → P02 → P03 → P04 → P05 |

完整执行时，每个版本有 12 人评价，每组在每个位置出现次数相同。这是轮转平衡，不消除所有前后相邻材料影响。

## 给参与者的说明

“我们在研究短句的阅读感受。请逐条阅读并按自己的感受评分，完全不好笑也可以。你可以跳过任何一条或随时退出。回答不会影响任何评价或关系，请不要与其他参加者讨论材料后再作答。”

展示纯文本，字体与字号一致。不显示作者、A/B 标签、机制解释或预期效果。执行人不给示范笑声，不追问“你怎么没笑”。

每条后问：

1. 你觉得多好笑？0 完全不好笑，3 中等，6 非常好笑。
2. 你觉得自己理解了多少？0 完全没懂，3 部分理解，6 完全理解。
3. 你觉得多意外？0 完全能预料，3 中等，6 非常意外。
4. 你觉得多不舒服？0 完全没有，3 中等，6 非常不舒服。
5. 你愿意再听类似表达吗？0 完全不愿意，3 一般，6 非常愿意。
6. 你觉得文字多自然？0 非常不自然，3 一般，6 非常自然。
7. 此前是否见过相同或很相似的表达？是 / 否 / 不确定。

自由反馈可选。所有题目可空缺；空缺不能记为 0。这里除借鉴趣味端点外，其余题目是项目自定，未经量表验证。

## 分析方案：先冻结，再看结果

主要指标只有好笑评分。对每个 A、B 都至少有两个有效好笑评分的参与者，计算：`个人差值 = B 均分 − A 均分`。报告平均个人差值、中位个人差值、正/零/负差值人数和有效人数；零差值按未四舍五入的值判断。

个人比较包含不同题材，依靠互补列表平衡；不能称为“同一个人对同一个笑话的配对比较”。同时逐材料报告 A、B 的有效人数、均分、中位数、分布和 B−A；避免总体结果掩盖题材差异。

如需不确定性区间：以参与者为重采样单位，对个人差值做 10,000 次 bootstrap，固定种子 20261012，给出 95% 百分位区间。这个区间针对当前固定六组材料与类似受众，不反映新题材的不确定性。小样本不以是否跨零作唯一判断，也不把区间解释成效果有 95% 概率落在其中。

理解、意外、不适、愿意再听、自然度作为次要描述指标，不事后挑一项作为主要“成功”。理解低分和不适高分不作为排除理由。熟悉度为“是”的记录保留在主分析中，另做移除已见表达的敏感性描述；若方向变化就报告。

执行前建议把 0.5 分设为项目暂定的实际值得关注差异，同时报告原始差值；这是项目判断门槛，未经验证，不是行业标准。

## 缺失、退出与排除

- 退出后按参与者意愿保留或删除其记录，留下不含身份的数量说明。
- 技术失败、重复提交等排除须写明原因；重复时保留首次有效提交。
- 单项缺失只影响该项汇总；少于各两条 A/B 好笑评分者不进入主要个人差值汇总，但其有效单条记录可进入材料描述。
- 报告招募人数、完成数、退出数、主要分析人数和每项有效数。人数未达目标就写实际人数，不为追逐方向反复加人。
